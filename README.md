# Airline Ticket Data Analysis Dashboard 
An interactive Power BI dashboard designed to analyze airline ticket sales, revenue, travel distance, booking behavior, and airline performance. The dashboard transforms raw airline data into dynamic visual insights through KPI cards, interactive charts, slicers, and data-driven reports.
The analysis provides a detailed view of revenue by travel class, ticket distribution by origin, distance by class, airline performance, and the relationship between booking lead time and revenue.
The dashboard highlights key business insights, including the strong revenue contribution of First and Business Class, the high travel volume generated by Economy Class, the leading performance of Mumbai as an origin, and the strong revenue and distance performance of Emirates.
## Tools: 
Power BI Desktop | Power Query | DAX | Data Modeling | Slicers | Interactive Visualizations | KPI Cards | Data Cleaning | Data Transformation | Data Analysis | Dashboard Design | Data Storytelling
